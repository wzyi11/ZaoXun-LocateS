## Goal

把 SpacePage 根层级（`breadcrumb.length === 0`）点击"+"按钮后添加**空间**的交互，从当前的 `Stack` 全屏遮罩弹窗（`AddDialog`）替换为 `bindSheet` 半屏面板。面板包含：空间名称输入、拍照或相册选择空间封面图。**分区**（section）的添加流程（SpaceDetail 中点击图片 marker 弹出 AddDialog）保持原样不动。

## Scope / Non-goals

**Scope:**
- 根层级"添加空间"：从全屏 Stack 弹窗 → `bindSheet` 半屏
- 半屏内容：空间名称 TextInput + 拍照按钮 + 从相册选择按钮 + 图片预览缩略图 + 保存按钮
- 拍照使用 `cameraPicker.pick()`（需 CAMERA 权限）
- 相册使用 `picker.PhotoViewPicker`（无需额外权限）
- 选中的图片复制到 app 私有目录，以 `file://` URI 存入 Space 的 `image` 字段

**Non-goals:**
- **不修改**分区（section）的添加流程（SpaceDetail 中 marker 点击 → 仍然用 `showAddDialog` + `AddDialog`）
- **不修改** `SpaceModel` 接口（`image` 字段已存在）
- **不修改** `SpaceRepository`（`insert` 已接受 `image` 字段）
- **不修改**其他页面（ItemPage, EventPage, ProfilePage 等）

**ArkTS 约束：**
- `@Builder` 内不能直接 `await`，异步逻辑需抽到普通方法中
- `bindSheet` 的 `height` 使用百分比字符串（如 `'75%'`，与 ItemPage 保持一致）
- `cameraPicker.pick()` 返回 `CameraPickResult`，需要 `ohos.permission.CAMERA`
- `picker.PhotoViewPicker` 不需要权限

## Design

### 方案：新增 bindSheet + 保留原有 dialog

**核心思路：** 不动 `showAddDialog` / `AddDialog()` 的任何代码（它们继续服务于分区添加），新增一套平行的 `showAddSheet` / `addSpaceSheet()` 专门服务于根层级的空间添加。

### 状态变量新增（SpacePage）
```typescript
// 半屏面板状态（仅用于根层级添加空间）
@State showAddSheet: boolean = false;
@State sheetKey: number = 0;
@State selectedImageURI: string = '';   // file:// URI
@State selectedImageName: string = '';  // 用于缩略图下方显示文件名
```

### 半屏 Builder（addSpaceSheet）
布局结构（参考 ItemPage.addItemSheet 的样式）：
```
Column {
  Text('添加空间')                    // 标题（可选，bindSheet 已有 title）
  Scroll {
    Column {
      // 空间名称
      Text('空间名称')
      TextInput { placeholder: '输入空间名称' }
        .onChange → 更新 newSpaceName

      // 空间图片

        Image(selectedImageURI)       // 缩略图预览
          .width('100%').height(160).objectFit(Cover).borderRadius(10)
        Text(selectedImageName)       // 文件名
          .fontSize(12).fontColor('#999')
      }
      Row {
        Button('📷 拍照')   → takePhoto()
        Button('🖼 从相册选择') → pickFromAlbum()
      }
    }
  }
  .layoutWeight(1)

  // 保存按钮
  Button('保存')
    .enabled(newSpaceName.trim().length > 0)
    → addSpace()
}
```

### 拍照方法（takePhoto）
```typescript
async takePhoto(): Promise<void> {
  try {
    const result = await cameraPicker.pick();   // 来自 @kit.CameraKit
    if (result.resultUri) {
      const destUri = await this.copyImageToAppDir(result.resultUri);
      this.selectedImageURI = destUri;
      this.selectedImageName = 'camera_photo.jpg';
    }
  } catch (err) {
    // 用户取消或权限不足，静默处理
  }
}
```

### 相册方法（pickFromAlbum）
复用 BackgroundSettingsPage 的 `pickCustomImage()` 模式：
```typescript
async pickFromAlbum(): Promise<void> {
  const options = new picker.PhotoSelectOptions();
  options.MIMEType = picker.PhotoViewMIMETypes.IMAGE_TYPE;
  options.maxSelectNumber = 1;
  const photoPicker = new picker.PhotoViewPicker();
  const result = await photoPicker.select(options);
  if (result.photoUris.length > 0) {
    const destUri = await this.copyImageToAppDir(result.photoUris[0]);
    this.selectedImageURI = destUri;
    this.selectedImageName = 'album_photo.jpg';
  }
}
```

### 图片复制辅助方法
```typescript
async copyImageToAppDir(srcUri: string): Promise<string> {
  const context = getContext(this) as common.UIAbilityContext;
  const destPath = `${context.filesDir}/space_${Date.now()}.jpg`;
  const srcFile = fs.openSync(srcUri, fs.OpenMode.READ_ONLY);
  const stat = fs.statSync(srcFile.fd);
  const buf = new ArrayBuffer(stat.size);
  fs.readSync(srcFile.fd, buf);
  fs.closeSync(srcFile);
  const destFile = fs.openSync(destPath, fs.OpenMode.READ_WRITE | fs.OpenMode.CREATE | fs.OpenMode.TRUNC);
  fs.writeSync(destFile.fd, buf);
  fs.closeSync(destFile);
  return `file://${destPath}`;
}
```

### build() 修改
1. 在 Stack 上添加 `.bindSheet()`:
```typescript
.bindSheet(this.showAddSheet, this.addSpaceSheet, {
  height: '75%',
  dragBar: true,
  showClose: true,
  title: { title: '添加空间' },
  onDisappear: () => {
    this.showAddSheet = false;
    this.resetSheetForm();
  },
})
```
2. 根 FAB onClick 改为 bindSheet 触发模式:
```typescript
.onClick(() => {
  this.resetSheetForm();
  this.showAddSheet = false;
  this.sheetKey++;
  this.showAddSheet = true;
})
```
3. 保留 `if (this.showAddDialog) { this.AddDialog() }` 不动（服务于分区添加）

### 为什么保留 AddDialog 不动
- SpaceDetail 中 marker 点击 → `showAddDialog = true` → `AddDialog()` 弹出
- 该 dialog 紧耦合 `pendingMarkerX/Y` 位置逻辑 + `getLevelLabel()` 标题
- 用户需求仅针对根层级的"添加空间"，不涉及分区
- 改动最小、风险最低

## Risks And Compatibility

| 风险 | 级别 | 缓解 |
|---|---|---|
| `cameraPicker.pick()` API 可用性（需 HarmonyOS 4.0+） | 低 | 项目 targetSdkVersion 为 6.1.1(24)，完全支持 |
| CAMERA 权限被用户拒绝 | 中 | `takePhoto()` 内部 try-catch 静默处理；用户仍可通过相册选择图片 |
| bindSheet 在 Stack 上绑定的兼容性 | 低 | 与 ItemPage 完全相同的用法（Stack→bindSheet），已验证可行 |
| `@Builder` 中不能直接 await | 低 | 所有异步逻辑放在独立方法中，Builder 内通过 onClick 触发 |
| 文件复制失败（存储空间不足） | 低 | try-catch 包裹，失败时 image 字段为空字符串，不影响空间创建 |
