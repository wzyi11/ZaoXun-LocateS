## Design

### 1. 新增 `setPendingMarkerFullscreen` 方法

全屏中无 Scroll，直接用 `display.getDefaultDisplaySync()` 获取屏幕尺寸计算相对坐标：
```typescript
setPendingMarkerFullscreen(event: ClickEvent): void {
  const displayInfo = display.getDefaultDisplaySync();
  const rawX: number = Number(event.x);
  const rawY: number = Number(event.y);
  const x: number = Math.max(0.06, Math.min(0.94, rawX / displayInfo.width));
  const y: number = Math.max(0.08, Math.min(0.92, rawY / displayInfo.height));
  this.pendingMarkerX = x;
  this.pendingMarkerY = y;
}
```

需要 `import { display } from '@kit.ArkUI'`（`router` 已从此 kit 导入，只需追加 `display`）。

### 2. SpaceDetail 图片区改动

- 删除两处 Image 的 `.onClick(event → setPendingMarker)`
- 删除 `if (this.hasPendingMarker()) { Button('+')... }` 整块
- 保留 ForEach 标记 ✅
- 保留浮动 "🔍" 按钮 ✅

### 3. fullscreenImagePreview 改动

结构变为：
```
Stack {                                    ← 全屏黑底
  Column().backgroundColor('#FF000000')    ← 黑底背景

  Image(...).objectFit(Contain)            ← 保持不变
    .onClick(event → setPendingMarkerFullscreen)  ← 新增

  ForEach(spaces, section → {              ← 新增：标记叠加
    Column { Circle(28) + Text(name) }
      .position({ x: markerX%, y: markerY% })
  })

  if (hasPendingMarker()) {                ← 新增：放置标记的 "+"
    Button('+').width(28).height(28)...
      .position({ x: pendingX%, y: pendingY% })
  }

  Button('✕')                              ← 关闭按钮不变
}
```

"+ " 按钮从 54×54 改为 28×28（与 Circle 的 `.width(28).height(28)` 一致），`fontSize` 调整为 16。
