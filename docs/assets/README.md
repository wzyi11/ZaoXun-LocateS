# Asset Index

Supporting visual and generation assets are grouped by purpose:

- `posters/`: poster exports and redesigns.
- `charts/`: standalone data visualizations.
- `screenshots/`: loose screenshots that are not part of a flow set.
- `figures/`: app-flow figures, cropped screens, and figure generation sources.
- `diagrams/`: Mermaid, Excalidraw, SVG, and rendered diagram files.
- `scripts/`: Python scripts used to generate posters, charts, diagrams, or documentation metrics.
